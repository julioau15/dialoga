##  Sobre o Projeto

O **DiaLoga** é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC), com o objetivo de utilizar a tecnologia para facilitar a comunicação e o acompanhamento entre pacientes e profissionais.

A plataforma busca oferecer recursos que auxiliem na organização, no acompanhamento e na comunicação, proporcionando uma experiência acessível e intuitiva para seus usuários.

---

##  Objetivo

Desenvolver uma solução digital que facilite a interação entre pacientes e profissionais, permitindo uma melhor organização das informações e funcionalidades relacionadas ao acompanhamento dos usuários.

---

##  Estrutura do Projeto

O DiaLoga é dividido em três aplicações principais.

###  Backend

Responsável pelas regras de negócio, processamento das informações, comunicação com o banco de dados e disponibilização das funcionalidades através de uma API.

🔗 [Acessar repositório do Backend](https://github.com/julioau15/backend-dialoga)

###  Frontend

Responsável pela interface web da plataforma, permitindo que os usuários interajam com as funcionalidades do sistema através do navegador.

🔗 [Acessar repositório do Frontend](https://github.com/julioau15/frontend-dialoga)

###  Mobile

Aplicação mobile desenvolvida para permitir o acesso às funcionalidades da plataforma através de dispositivos móveis.

🔗 [Acessar repositório do Mobile](https://github.com/julioau15/mobile-dialoga)
